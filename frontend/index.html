📋 Bridge Setup Instructions

MT5 EA Setup (File Bridge)

  1. Copy bridge/mt5_bridge.mq5 → your MT5 terminal's MQL5/Experts/ folder
  2. Open MetaEditor F4 → compile the EA F7
  3. Attach the EA to any chart (e.g. XAUUSD M1)
  4. Set BridgeSecret input to match MT_BRIDGE_SECRET in your .env
  5. Add to .env: MT4_FILES_DIR=C:\Users\YOU\AppData\Roaming\MetaQuotes\Terminal\HASH\MQL5\Files
  6. Set SIMULATION_MODE=false to go live

File Bridge Flow

Node.js → writes cmd.json → MT5 EA reads on tick → executes trade → writes resp.json → Node.js reads
